१. सबैभन्दा पहिले config.js फाइल Notepad मा खोल्नुहोस्.
२. PASTE_YOUR_PROJECT_URL_HERE को ठाउँमा Supabase Project URL राख्नुहोस्.
३. PASTE_YOUR_PUBLISHABLE_KEY_HERE को ठाउँमा Supabase Publishable key राख्नुहोस्.
४. दुवै मानहरू double quotes भित्रै राख्नुहोस् र Ctrl+S थिचेर Save गर्नुहोस्.
५. Secret key वा service_role key वेबसाइटमा कहिल्यै नराख्नुहोस्.
६. GitHub repository मा यी सबै फाइलहरू upload गरेर पुराना फाइलहरू replace गर्नुहोस्.
७. वेबसाइटमा admin.html खोल्नुहोस् र Supabase Auth मा बनाएको admin email/password बाट login गर्नुहोस्.

महत्त्वपूर्ण: यो static website template हो. Supabase मा पहिले बनाइएको posts table र admin policies ठीकसँग सेट भएको हुनुपर्छ.
