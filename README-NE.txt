THOUGHT CIRCLE — साहित्य र समाचार पोर्टल (प्रारम्भिक नमुना)

सुविधा:
- नेपाली/अंग्रेजी भाषा टगल
- राष्ट्रिय, अन्तर्राष्ट्रिय समाचार, साहित्य र विचार विभाग
- मोबाइलमैत्री डिजाइन
- स्थानीय डेमो एडमिन प्यानल
- थपिएका डेमो सामग्री JSON मा निर्यात गर्ने सुविधा

कसरी खोल्ने:
1. ZIP फाइल Extract गर्नुहोस्।
2. index.html मा double-click गर्नुहोस्।
3. ब्राउजरमा नमुना वेबसाइट खुल्छ।

महत्त्वपूर्ण सीमाहरू:
- यो स्थिर वेबसाइट नमुना हो; इन्टरनेटमा प्रकाशित छैन।
- एडमिन प्यानल सुरक्षित लगइन होइन र सामग्री सार्वजनिक वेबसाइटमा प्रकाशित गर्दैन।
- एडमिनमा थपिएका सामग्री हालको ब्राउजर सत्रमा मात्र रहन्छन्; आवश्यक भए JSON निर्यात गर्नुहोस्।
- वास्तविक समाचार पोर्टलका लागि सुरक्षित CMS/backend, admin authentication, database, image upload र hosting जोड्नुपर्छ।
- समाचार प्रकाशित गर्नुअघि स्रोत, मिति र तथ्य जाँच्नुहोस्। नमुना शीर्षक/विवरणहरू वास्तविक ताजा समाचार होइनन्।
- Google Fonts को राम्रो प्रदर्शनका लागि इन्टरनेट चाहिन सक्छ।

निःशुल्क प्रकाशित गर्ने अर्को चरण:
GitHub Pages वा Netlify मा स्थिर साइट होस्ट गर्न सकिन्छ। तर सुरक्षित admin publishing र database का लागि छुट्टै सेवा/सेटअप चाहिन्छ।
